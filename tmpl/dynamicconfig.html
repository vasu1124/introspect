How Dynamic ConfigMap Synchronization Works

The introspect-dynconfig ConfigMap is mounted into the container at /etc/config/dynconfig/. When updated via the editor or kubectl, Kubernetes updates the volume mount directory symlinks atomically. An internal Go fsnotify watcher detects the file system event, reloads the configuration in memory without restarting the pod, and broadcasts the new state over WebSocket to this page in real-time.
