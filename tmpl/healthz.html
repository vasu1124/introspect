How It Works

Liveness Probe (/healthz)

  • GET /healthz?die - Sets liveness to 500 (pod will be restarted)
  • GET /healthz?live - Sets liveness to 200 (pod is healthy)
  • Default: 200 OK
  • Kubernetes restarts pod when liveness fails

Readiness Probe (/healthzr)

  • GET /healthzr?die - Sets readiness to 503 (pod removed from service)
  • GET /healthzr?live - Sets readiness to 200 (pod receives traffic)
  • Default: 200 OK
  • Kubernetes stops sending traffic when readiness fails
