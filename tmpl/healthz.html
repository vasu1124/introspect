Health Checks

Monitor and control Kubernetes liveness and readiness probes for this pod

Liveness Probe (/healthz)

Kubernetes liveness probe - determines if pod should be restarted

Alive 200

Readiness Probe (/healthzr)

Kubernetes readiness probe - determines if pod receives traffic

Ready 200

How It Works

Liveness Probe (/healthz)

  • GET /healthz?die - Sets liveness to 500 (pod will be restarted)
  • GET /healthz?live - Sets liveness to 200 (pod is healthy)
  • Default: 200 OK
  • Kubernetes restarts pod when liveness fails

Readiness Probe (/healthzr)

  • GET /healthzr?die - Sets readiness to 503 (pod removed from service)
  • GET /healthzr?live - Sets readiness to 200 (pod receives traffic)
  • Default: 200 OK
  • Kubernetes stops sending traffic when readiness fails

Kubernetes Probe Configuration Reference 

livenessProbe:
  httpGet:
    path: /healthz
    port: 9090
  initialDelaySeconds: 10
  periodSeconds: 10
  failureThreshold: 3

readinessProbe:
  httpGet:
    path: /healthzr
    port: 9090
  initialDelaySeconds: 5
  periodSeconds: 5
  failureThreshold: 3
